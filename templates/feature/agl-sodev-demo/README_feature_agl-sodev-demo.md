### Feature agl-sodev-demo

* Enables support for building multiconfig based SoDeV demo images

### Dependent features pulled by agl-sodev

The following features are pulled:

* agl-sodev
* agl-sodev-platform
* agl-demo

Note that enabling this feature results in a configuration where building images
other than AGL SoDeV demos may not give the desired results.
